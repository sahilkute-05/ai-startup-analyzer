# What is an AI Agent?

## Definition

An AI Agent is a software component that uses an LLM, instructions, and optionally tools or memory to perform a specific task.

## In Our Project

Every agent inherits from `BaseAgent`.

Examples:
- Planner Agent
- Research Agent
- Competitor Agent
- Tech Stack Agent

## Key Characteristics

- Has a specific role
- Receives a task
- Produces an output
- Can collaborate with other agents
